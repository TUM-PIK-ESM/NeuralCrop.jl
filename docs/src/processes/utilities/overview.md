# Utilities

Utility functions support data loading, normalization, plotting, and date/index conversion.

## NetCDF loading

Utilities load one-dimensional and multi-dimensional variables from NetCDF files for selected time ranges or grid locations.

## Normalization

Normalization helpers support min-max and z-score style transformations used by neural-network inputs and training targets.

## Visualization

Visualization utilities include helpers for plotting loss curves and loading output data for analysis.
