# Hybrid components

Hybrid components live in `src/hybrid` and replace selected process-based calculations with neural-network outputs.

## Crop hybrid components

Crop hybrid routines cover photosynthesis and crop carbon related processes.

## Soil hybrid components

Soil hybrid routines cover soil water, soil carbon, and soil nitrogen updates.

## Design goal

The goal is to train data-driven components inside the physical crop model, rather than fitting isolated post-processing corrections.
