# Soil processes

Soil processes update water, carbon, nitrogen, temperature, and snow-coupled state variables.

The soil state includes layer-wise soil water, litter carbon and nitrogen, fast and slow carbon and nitrogen pools, nitrate, ammonium, runoff, percolation, evaporation, and snow variables.

## Layer structure

Many soil arrays are stored as `(layers, cells)`. Litter and mineral soil pools can use different layer counts.
